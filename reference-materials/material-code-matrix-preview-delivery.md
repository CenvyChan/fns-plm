# 物料编码矩阵预览交付摘要

此处只保留通用设计结论，不包含企业产品字典、真实物料样本、组织/账套信息、ERP 映射或可执行载荷。详细参考资料已移至受控私有存储，未随公共代码发布。

## 行为边界

物料编码矩阵只用于候选规则预览。预览不占号、不写分配数据库、不调用 ERP；未批准规则保持草稿状态，候选载荷不可直接执行。已存在的业务分配、权限与 ERP 数据必须按明确 scope 隔离。

## 可复用设计

- 物料主分类与可复用维度分开维护；
- 规格身份字段由受控规则明确列出，不能把任意文本直接当去重键；
- 完整编码须做跨规则、跨版本碰撞检查；
- 正式分配使用事务、唯一约束和幂等键；
- ERP 元数据、字段映射和写入流程需在专用测试范围独立验证。

本文件不是生产批准单、ERP 验收报告或真实业务数据来源。
