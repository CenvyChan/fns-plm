# K3 报表候选预检

## 当前状态

本项目保留通用报表候选目录和本地合成 fixture，但不保留真实账套验证记录。历史观察值、映射、业务行和网络端点已从此分支移除；它们不能被解释为当前运行环境的授权、字段契约或查询结果。

库存、收发存、采购执行、销售执行和账龄属于不同能力。候选 FormId、字段、组织筛选、分页、币别和指标口径都需在明确授权的环境中逐项验证。未验证前，实时查询保持锁定；不得由本地 fixture、历史报告或字段名称推定真实数据。

## 安全边界

- 报表候选与字段合同是待核验的设计信息，不是已确认的账套映射。
- 本地 fixture 仅用于界面、过滤、分页和响应契约测试，必须明确标记为合成数据。
- 任何 K3 请求都必须由当前账号范围内的显式配置和服务端只读 allowlist 控制；本地测试只使用隔离 mock。
- 库存组织、仓库、物料、单位、数量、可用量、金额和期间关系都需来源证据，不可由界面或样例推算。
- 独立库存接口不得与表单查询混为一谈；未验证响应结构和限量语义时保持禁用。

## 后续验证条件

只在专用测试范围完成字段发现、只读请求契约和合成/mock 回归后，才能更新候选状态。任何真实业务行均不应进入仓库或 QA 截图；只记录经过批准且不含账户识别信息的验证结果。本说明不授权 K3 请求或环境变更。
