# Momentum PLM 用户操作指南

## 1. 首次启动与企业范围

- 首次打开应用时创建平台管理员；这一步建立管理身份，不要求预先伪造企业租户、组织或账套。
- 登录后进入 **租户与账套**，创建企业租户、组织和账套，再邀请成员并分配角色。成员由本人使用一次性激活链接设置个人密码；不要分发共享默认密码。
- 新账套默认从空白工作区开始，避免演示数据被当成真实业务记录。既有账号为避免迁移时突然锁定，会保留旧密码，直到平台管理员逐人签发密码重设链接；签发后旧密码和现有会话立即失效。
- 业务 API 必须先认证，再由服务端验证租户、组织、账套和角色权限。客户端提交的范围标识不会替代服务端成员关系校验。

## 2. 个人待办与企业项目

- 在 **待办** 中创建、编辑、完成或删除任务，可设优先级、起止/截止日期、项目、阶段、里程碑、WBS 编码、预计工时与验收标准。保存以服务端成功响应为准；刷新后从当前账套重新读取。
- 在 **项目进度** 管理项目组合、目标与范围、负责人、状态、进度、阶段门、里程碑和任务计划。**甘特图**按周展示阶段、任务、里程碑和事件的计划区间、进度及逾期状态；阶段及里程碑可关联项目任务，并保留计划/实际日期和验收标准。
- 管理员或 PLM 管理员可选择内置 **产品开发、工程变更、质量改进、企业系统实施、设备导入与验收** 项目模板，原子创建项目及其阶段、里程碑和任务；也可创建自定义模板。模板生成后可按项目实际情况调整。
- 项目负责人、任务负责人必须属于当前启用账套；任务前置依赖仅允许引用同一项目的现有任务，不允许自依赖/循环依赖，有后续依赖的任务需先解除关系才能删除。
- 项目计划支持导入 CSV/XLSX，导入会先验证阶段/里程碑引用、重复编码、日期和字段，再按项目范围写入；支持导出 CSV/XLSX，以及包含项目附件的 ZIP 归档。计划导入限 10 MB；单附件限 25 MB。请先备份再进行批量导入。
- 项目事件可关联阶段、里程碑、任务和项目权重，并记录风险、问题、决策、变更、交付物等事项。项目成员可以提交自己负责事件的自评；绩效审核需由另一位有评审权限的人完成，审核记录与指标规则快照会保留，已评审的事件不能直接重新打开覆盖审核上下文。
- 项目周报/阶段报告可记录进度、成果、阻塞、风险、待决策事项和下一步；附件和导出数据均受当前账套访问控制。

## 3. 企业 PLM 主数据

- **KPI / 绩效**：管理员或 PLM 管理员可新增、编辑核定规则；每次修改都会递增规则修订号。草稿规则仅在未被绩效记录或评审快照引用时可以删除；生效规则必须先通过目标生效集完成替换，已被历史评审引用的规则保留用于审计。目标值须为正数，权重须在 0–100 之间。勾选目标生效集后，必须一次性提交，且启用规则的权重合计必须严格为 **100%**，不能逐条切换造成半配置状态。通用绩效表单由管理员、PLM 管理员或评审角色创建/评审；项目事件绩效另按负责人自评、独立评审人复核的流程处理。
- **物料主数据**：按物料编号或名称检索，维护基础属性、单位及生命周期。未配置真实 K3Cloud 前，ERP 编码不会被伪装为已同步。
- **BOM 清单**：维护 EBOM、MBOM、SBOM、版本和行项目，并支持配置属性、销售规则、版本历史及订单快照。当前不执行 ERP 下单或写回。
- **图文档中心**：登记文档编号、关联物料、修订和生命周期；允许类型的附件可上传、按版本查阅及受保护下载。可在附件历史中预览 PDF/图片、DOCX 正文、XLSX 首个工作表和 CSV/TXT；解析在浏览器本地完成，不上传到第三方预览服务。复杂 Office 排版不保证还原；DWG/DXF/STEP/STL/IGES 等 CAD 文件可受保护下载，但当前不提供在线 CAD 查看器。实际允许格式由页面提示与服务器校验决定。

## 4. 审批、报告与连接器

- **流程待办**：当前账套未配置 Flowable 时，页面会标记本地演示模式；演示审批和审计记录会持久化，但不代表已触发外部企业流程。连接 Flowable 并配置用户映射后，审批模块才会调用真实流程引擎。
- **报告中心**：报告预览使用当前账套数据，可建立、暂停、删除日报/周报计划并查看运行记录。钉钉未配置时，发送操作会被禁用或由服务端拒绝，不会声称已经发送。
- **系统集成**：管理员按账套配置 Flowable、K3Cloud 和钉钉。凭证使用 AES-256-GCM 加密保存；生产部署需设置并备份独立的 `APP_ENCRYPTION_KEY`。K3Cloud 查询只使用服务端已配置的 `FormId → FieldKeys` allowlist，不提供自由查询表达式或写单据能力。
- **钉钉小程序**：使用一次性 authCode，由服务端向钉钉验证并交换身份，再匹配已有工作区用户。只有平台管理员能维护钉钉身份绑定；工作区角色和范围仅来自有效成员关系，停用成员的会话会被撤销。真实企业免登需配置企业 App 凭证和用户映射；钉钉机器人 Webhook 不等于 SSO。

## 5. 建议验收步骤

1. 创建平台管理员并登录；建立测试企业、组织及账套。
2. 邀请不同角色成员，通过本人专属的一次性激活链接设置密码；验证访问边界和切换账套隔离。
3. 从模板创建项目，更新阶段、里程碑和任务；导出计划后再导入一份测试 CSV/XLSX，刷新页面确认结果仍在。
4. 新增物料、BOM、图文档和附件，验证字段校验、附件读取及版本历史。
5. 建立两条权重合计 100% 的 KPI 规则并原子启用；完成项目事件，验证负责人自评和另一位评审人批准。
6. 在未连接 Flowable/钉钉时，确认系统明确显示演示或未配置状态；需要生产连接时，在 **系统集成** 设置真实服务地址、allowlist 和凭证，再分别测试连接。
7. 生产上线前按 [Ubuntu 运维手册](../deploy/ubuntu/README.md)配置 TLS、密钥、备份、恢复演练和发布回滚；不要将生产 secret 放入代码、公开仓库或截图。

接口字段与错误码见 [API 手册](API.md)，集成配置见 [集成说明](INTEGRATIONS.md)，项目管理模型与依据见 [项目管理模型](PROJECT_MANAGEMENT_MODEL.md)。
