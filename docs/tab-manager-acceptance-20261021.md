## 用户可以直接验收的变化

打开 **8 个及以上**页签时，会出现持续的数量提示和“页签较多”提醒，不会自动关闭任何后台页签。固定的“管理页签”按钮打开原生模态弹窗，支持逐项勾选、全选、清空选择，以及“选择其他已保存页签”。零选择时不能执行关闭。

弹窗完整展示业务标题，并标记当前/后台页签及未保存内容。长标题在页签栏省略显示，鼠标悬停可查看完整标题；弹窗中可换行查看。键盘 Escape 可以返回，焦点回到管理按钮。

业务标题随已加载记录的详情或编辑上下文更新，不把未保存输入当成正式编码，也不把业务标题写入页签持久化数据：

| 场景 | 已在浏览器读取的实际标题 | 取值规则 |
| --- | --- | --- |
| 销售日报编辑/详情 | `销售日报 · 2026-10-21 · #NAV-SALES-026` | 已保存的 `date` + `documentNo`；没有流水码时退回记录 `id`；无当前记录的列表仅显示类型和日期 |
| 采购日报列表 | `采购日报 · 2026-10-20` | 与销售日报区分，未选择记录时不拿另一类日报的默认对账选择充当当前记录 |

| 有编码任务编辑 | `任务 · 页签管理有编码任务 · #TAB-QA-001` | `Task.title` + 真实模型中的 `wbsCode` |

## 草稿保护的实际验收

1. 新增销售日报，在备注输入 `TAB-MANAGER-UNSAVED-保留草稿`，不保存，切到时间线。后台页签保留表单和值，显示未保存标记。
2. 在管理弹窗中同时选择该草稿页签和普通的流程审批页签，点击“关闭所选（2）”。浏览器明确提示有 1 项未保存内容，并列出标题及关闭整批数量。
3. 选择取消后，**3 个页签仍全部存在、2 项勾选仍保留**。返回日报编辑，备注原文完整保留。不是先关普通页签、再询问草稿。
4. 后续全选 4 个页签再次关闭，仍先询问未保存内容。明确接受丢弃本地测试草稿后才关闭全部，并自动回到唯一的总览页签。
5. 再关闭唯一的总览页签，仍保留可用总览面板，不会出现空白工作区。

任务、项目的全局编辑弹窗也被绑定到打开时所属页签。为安全起见，打开全局表单即按未保存处理；只有整批确认通过后才通知所属全局表单关闭。此保护对未修改表单可能略保守。

## 边界与限制

仍沿用原工作区的“每个业务 family 一个页签”模型，没有扩展为同一业务可同时打开多个独立记录页签。标题反映该 family 当前的详情/编辑记录；关闭详情或表单后可回到列表标题。同类记录的区分依赖现有真实业务编码/实例 ID，不新增服务端编码规则。

未实现跨刷新恢复草稿。切页保留的是内存中的活面板；刷新/退出仍使用原有未保存提醒。未把草稿或敏感表单值写入 sessionStorage。现有 dirty 捕获机制继续复用，并为全局任务/项目表单补充保护；未对所有第三方自绘控件做穷尽式真机验证。

未部署，因此这些变化尚不在生产环境生效。
