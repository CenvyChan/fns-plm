# BPMN 流程设计器 UX 重做

本分支在 `0fdbc9694690c73cd97884d6091bc393a4c22e42` 上重做设计器，不只是调整颜色。原有 `bpmn-js`、服务端严格验证、权限与作用域隔离、草稿修订、不可变版本和 mock 发布门禁保留。

本说明是 `BPMN_MODELER_MVP.md` 的增量说明：基线文档原先不含的受限并行网关、固定表单版本绑定，在本分支开放；任意 XML 导入、脚本和真实引擎发布仍未开放。

## 现在可以做什么

- 三栏设计工作区：可搜索的模型清单、图形画布、节点与连线属性。流程名称和 Key 与图形操作分层，桌面支持专注设计。
- 从串行审批、条件审批、并行审批三个真实图模板创建草稿。增加用户任务时插入当前节点后并重接原有连线，同时移动下游节点，避免压住结束事件。
- 选中图形或通过节点选择器编辑显示名称；选择指定用户、候选用户或 PLM 工作区角色，不让用户输入原始 Flowable 身份。
- 显式增加、编辑和删除顺序流。新增连线立即打开属性编辑器，默认选择前方可连接目标，结束事件和已有非网关出线有明确防误操作提示。
- 条件流只提供 `approved`、`rejected` 和默认路径，不开放任意表达式。并行模板具有分发及合流，服务端拒绝不闭合或会提前逃逸的并行分支。
- 在内嵌表单管理中创建表单、编辑支持的字段、保存草稿和发布不可变版本。用户任务绑定 `formKey + formVersion`；发布表单 v2 不会改变已冻结流程绑定的表单 v1。
- 保存、校验、冻结版本与发布预览各有明确状态。差异显示节点、连线、角色和固定表单版本的可读摘要；确认框和按钮明确标记本地 mock 模拟发布。发布历史与审计可回读。
- 空态不冒充已打开的示例模型；错误有提示和重新读取入口。切换模型或新建时，未保存的流程修改需要确认丢弃；表单切换也有防丢失确认，存在未保存字段时禁止发布表单版本。
- 390 CSS 像素下通过模型、画布、属性、发布、表单五个面板切换，不强行压缩成三栏。头部操作压缩为可触达控件，节点也可从选择器定位，不依赖精细点击小图形。

原生 `bpmn.io` 水印没有隐藏、移动出视口或替换。390px 画布中的缩放与适配控件仍可使用；全图适配时节点会缩小，可转到属性面板编辑。

## 安全与运行边界

服务端仍强制管理员权限、tenant / organization / account 三维 scope、乐观并发修订号、冻结版本不可变、作用域/版本绑定的预览确认令牌，以及发布去重和不明确结果禁止自动重试。固定表单版本在冻结、预览、发布前检查当前 scope 中是否存在。

XML 只允许受控 BPMN 子集及最小 Flowable 属性。表单键只额外允许规范的 `plm-form:<安全key>:v<正整数版本>`，没有放宽其他身份属性。脚本、外部实体、外部资源、不受控扩展和任意表达式继续拒绝。

**真实 Flowable 8.0.0 未连接，真实发布仍被门禁阻断。** 本轮没有确认其 XXE 公告已修复，也没有通过修改配置绕开这一风险。验收使用临时 SQLite 与 loopback mock，没有生产凭据或生产数据。

表单运行时任务适配器未实现，任务提交 API 仍明确返回 501。并行分支不是多实例会签；候选组缺少 PLM 主账映射，不提供伪映射。高级表单选项/条件编辑、完整变量建模、跨图重建的撤销重做、任意 BPMN 导入和真实引擎部署不属于已完成能力。

## 本地复现

在本工作树执行：

```bash
npm ci --prefix client
npm ci --prefix server
npm run build --prefix client
npm run build --prefix server
npm test --prefix client
npm test --prefix server
cd server
node scripts/bpmn-modeler-mobile-preview.mjs
BPMN_PREVIEW_UI_PORT=4520 BPMN_PREVIEW_API_PORT=4521 BPMN_PREVIEW_MOCK_PORT=4522 node scripts/bpmn-modeler-preview.mjs
```

预览启动器只创建 `/tmp/bpmn-ui-isolated-*/ui.sqlite`，并输出合成登录账号和本地地址。不要复用生产 `.env`。390px 响应式入口是 `http://localhost:4520/bpmn-mobile-preview.html`，它在同源 iframe 中以实际 390 CSS 像素运行同一应用，不是手机设备模拟器。

浏览器验收步骤与结果见 [证据索引](../qa-evidence/bpmn-modeler-ux/README.md)。
