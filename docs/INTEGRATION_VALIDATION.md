# 本地报表与连接器验证边界

## 当前实现

仓库保留操作报表候选目录、本地合成 fixture、连接器安全边界和契约测试。采购、销售和库存演示数据不代表真实 ERP 行；候选报表字段、查询参数与映射都保持未验证，实时业务查询默认锁定。

## 验证范围

自动化测试使用临时数据库、合成范围和本地 mock。它们可验证路由鉴权、作用域隔离、参数校验、响应形状处理、fixture 筛选与分页，以及不得从未知响应输出原始数据等行为。测试结果不证明任何外部 ERP、审批引擎或生产环境已连接。

## 被移除的证据

未逐张审阅的 248 张页面截图、两份导出工作簿以及历史账套观察/映射已从当前分支删除。剩余旧 QA 图片不是本次新增或修改的证据；它们不应作为本候选报表的实测证明。详见 [QA 清理说明](../qa-evidence/REDACTION.md)。

## 安全边界

- 不访问 K3、不运行真实查询、不部署或修改远端配置。
- 不把本地 fixture、历史页面或字段名当作企业映射/授权。
- 每个真实连接必须由当前 scope 内加密配置与显式 allowlist 管理。
- 未验证组织、字段语义、分页与响应限量契约前，保持相应 live action 锁定。
