# PLM 导航重编排与验收摘要

此工作区曾完成业务分组、二级目录与受限页面导航调整。当前文档只记录通用行为，不保留专属账户、迁移对象、私有路径或真实业务数据。

## 导航结构

- 个人工作台：总览、待办、项目进度和时间线；
- 产品数据：物料、BOM 与图文档；
- 业务运营：经营日报、报告推送与 KPI；
- 流程协同：流程审批；
- 系统管理：成员权限、集成设置和范围管理。

原页面标识保持兼容；导航链接、面包屑、当前页状态和浏览器历史使用统一配置。不同 scope 切换时，工作区组件按完整范围重新挂载，避免复用前一范围的本地缓存。

## 通用验收项

自动化验证覆盖页面路由、角色可见性、越权深链接、刷新与浏览器前进/后退、跨 scope 切换、窄屏导航抽屉和无横向溢出。测试使用合成账号和隔离数据库；它不证明生产账户、ERP、审批引擎或真实业务记录已通过验收。

涉及真实数据迁移、第三方连接或生产部署的验收记录不包含在本文件中。具体截图和账号专属证据应保存在受控的私有存储中。
