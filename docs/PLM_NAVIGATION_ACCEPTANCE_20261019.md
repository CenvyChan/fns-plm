## 实现要点

`navigation.ts` 统一分组、名称与入口权限；`BusinessNavigation.tsx` 提供真正的页面链接、当前页状态、可折叠分组和键盘可访问性。侧栏与面包屑共用这份配置。

全部原页面支持 `?page=<原标识>`，导航同步地址栏，支持刷新和浏览器后退／前进，保留其他 query/hash。未知或越权入口回退总览并规范化 URL；登录验证完成前不渲染受限业务页面。

报表中心新增 `reportView=daily|delivery` 二级视图，保留表单和原操作。切换视图不会卸载另一面板并丢失编辑状态。

保留原租户／组织／账套选择器和服务端角色规则。工作区内容按完整 scope 三元组重新挂载，避免新账套复用上一账套组件内的缓存数据或表单。移动端增加关闭按钮、Escape、焦点约束、背景 inert、滚动锁和桌面断点清理。

## 实际界面验收

使用新建隔离 SQLite、正式初始化与登录 API 产生的一次性本地会话；未调用生产凭据。浏览器实际点击、检查页面内容和 URL，不以截图代替行为验收。

| 检查 | 实际结果 |
|---|---|
